# Reference Model

The reference model is the growing library of proven references that powers [Reference-Driven Delivery](../03-delivery/reference-driven-delivery.md). This is a first version.

## Purpose

Give teams proven starting points instead of blank pages: patterns, prior canvases, validated prompts, and reusable blocks with known behavior.

## What belongs in it

- Proven architecture and integration patterns.
- Prior [AI Impact Canvases](../02-ai-discovery/ai-impact-canvas.md) for recurring needs.
- Validated prompts and narrative/reporting models.
- Reusable [building blocks](../03-delivery/reusable-assets.md) and their behavior notes.

## How it grows

- Proven work from deliveries is promoted into the reference model via [continuous learning](continuous-learning.md).
- References are adapted, not blindly copied; deviations are recorded in the [decision log](../templates/decision-log.md).
- Stale or superseded references are retired.
