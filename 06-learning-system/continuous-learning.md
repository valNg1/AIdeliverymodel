# Continuous Learning

**Principle:** every delivery feeds the learning system. Learning is designed in, not hoped for.

## Why

"Delivery as an organizational capability" only grows if each delivery leaves the organization more capable. Continuous Learning is the mechanism that turns work into compounding capability.

## The loop

```
Deliver ──▶ Retrospect ──▶ Update references & knowledge ──▶ Better next delivery
   ▲                                                             │
   └─────────────────────────────────────────────────────────────┘
```

## What feeds the system

- Lessons from [retrospectives](retrospectives.md).
- Proven work promoted into the [reference model](reference-model.md).
- Captured knowledge (see [knowledge-first](../03-delivery/knowledge-first.md)).
- Run learnings, including the [research backlog](../05-product-operations/research-backlog.md).

## Where it connects

Continuous Learning is the *Learn* stage of the [lifecycle](../01-operating-model/lifecycle.md), and it feeds back into future Discovery. Progress is assessed against the [maturity model](maturity-model.md).
