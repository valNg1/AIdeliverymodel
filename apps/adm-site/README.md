# ADM Public Site

Public showcase for the **AI Delivery Model by Everboarding**.

Target URL: `https://adm.everboarding.fr`

Purpose:
- explain the method to clients and partners;
- present ADM agents and human gates;
- show selected applied cases without exposing private client data;
- provide selected public templates;
- onboard potential clients and partners;
- route authenticated users to `https://hub.everboarding.fr`.

## Local preview

Open this folder with VS Code Live Server.

## Deployment

Create a dedicated Vercel project with this folder as the project root:

`apps/adm-site`

Then attach the custom domain:

`adm.everboarding.fr`

No private project data should be added to this app.
