# Run Principles

> ⚠️ **Experimental area.** Product Operations / Run is not yet stabilized. This is a first version to adapt.

Principles for operating products in the AI Delivery Model.

- **Plan the Run before the Build.** Run impact is surfaced in Discovery via the [AI Impact Canvas](../02-ai-discovery/ai-impact-canvas.md).
- **Nothing runs unowned.** Every product and every supervision row has a named owner. See [ownership-model.md](ownership-model.md).
- **Supervise explicitly.** Use the [observability matrix](observability-matrix.md); "keep an eye on it" is not a plan.
- **The business owns its responsibilities.** Business rules, data quality, validation, thresholds, prompts, narrative models, supervision, and evolution.
- **Validate AI behavior continuously.** Human validation is ongoing, not one-time — see [human-validation](../03-delivery/human-validation.md).
- **Feed the Run back into Discovery.** What the Run reveals reshapes future needs and thresholds.
- **Be honest about maturity.** Present evolving Run practices as evolving; do not claim unobserved results.
