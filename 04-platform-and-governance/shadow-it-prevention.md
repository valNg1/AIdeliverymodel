# Shadow IT Prevention

When anyone can produce working software quickly, ungoverned initiatives multiply. This is a first version.

## The problem

Cheap, fast delivery is a benefit — until it happens outside any operating model. Then it produces duplicated effort, fragmented systems, unmanaged data, and unassigned Run responsibility. Heavy-handed control makes it worse: if the governed path is too slow, people route around it.

## The stance

Prevent shadow IT by making the governed path the *fastest* path, not by blocking people.

- Provide paved paths via [platform foundations](platform-foundations.md).
- Keep [portfolio governance](portfolio-governance.md) lightweight and quick.
- Make Discovery valuable, not bureaucratic: it should help teams, not gate them for its own sake.
- Assign ownership early so nothing runs unowned.

## Signals to watch

- Products in use with no named owner.
- Data flows nobody governs.
- AI usage with no validation or supervision.
