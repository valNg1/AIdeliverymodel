# Roadmap

This roadmap is indicative and will evolve. It describes intent, not commitments.

## v0.1 — Foundational structure (current)

- Repository structure and navigation.
- Fully written priority documents (vision, operating model, AI-native Discovery, AI Impact Canvas, Product Operations overview, core templates and prompts).
- Short first versions of all remaining files.

## v0.2 — Depth and worked examples (planned)

- Expand the short first-version files into complete documents.
- Add a fully worked, **generic** example: a fictional company running a Discovery workshop, producing an AI Impact Canvas end to end.
- Detail the standard-vs-AI delivery comparison with concrete before/after workflows.
- Strengthen the observability matrix with more object/metric patterns.

## v0.3 — Operability (planned)

- Mature the Product Operations / Run section as practices stabilize.
- Add a maintenance-model playbook and an ownership RACI reference.
- Add retrospective and maturity-assessment instruments.

## Later — Ecosystem (exploratory)

- A reusable building-blocks catalog format.
- A reference/pattern library structure for Reference-Driven Delivery.
- Optional tooling to run the augmented workshop prompts (kept separate from this documentation repository).

## How to influence this roadmap

Open an issue or a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).
