# Why now

Three shifts make this operating model timely.

**1. The cost of producing software is falling.**
AI-assisted delivery lowers the marginal cost of designing, writing, and integrating software. Work that once required outsourcing can increasingly be done in-house. This reopens the "build vs. buy" question for strategic products. See [from-buy-to-make.md](from-buy-to-make.md).

**2. Delivery now outpaces governance.**
When anyone can produce working software quickly, ungoverned and shadow initiatives multiply. Without an operating model, speed turns into fragmentation, duplicated effort, and unmanaged risk. See [shadow-it-prevention](../04-platform-and-governance/shadow-it-prevention.md).

**3. Products are built but not operated.**
The hard part is no longer only building; it is *running* what you build — supervising AI behavior, validating outputs, maintaining data quality, and assigning ownership. Many organizations discover the Run cost after they have already committed. This model brings that cost forward into Discovery.

**The window.** These shifts are happening together. Organizations that build a repeatable capability now — rather than reacting later — gain a durable advantage. This repository is a starting point for that capability.
